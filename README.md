# Домашнее задание №8: Деревья решений (Базовый уровень)

## 📌 Описание

В этом задании реализованы ключевые концепции деревьев решений:

- Реализация трёх мер качества разбиения для задач классификации:
  - **Gini**
  - **Entropy**
  - **Classification Error**
- Обучение и визуализация решающего дерева на датасете **California Housing**
- Анализ переобучения с помощью **GridSearchCV** (перебор глубины от 1 до 30)
- Сравнение с линейной регрессией (**RidgeCV**) с масштабированием и без
- Оценка важности признаков через `feature_importances_`

## 🛠 Стек

- Python 3.8+
- scikit-learn
- Pandas
- Matplotlib / Seaborn
- Plotly

## 📊 Датасет

**California Housing** — классический датасет для задач регрессии.  
Целевая переменная: **медианная стоимость дома** (в сотнях тысяч долларов).

## 🧠 Основные выводы

1. Дерево решений глубины **3** даёт интерпретируемую модель с предсказаниями по цепочке условий.
2. С ростом глубины дерево **переобучается** — тренировочная ошибка падает до нуля, а валидационная растёт.
3. **Масштабирование признаков** не влияет на качество дерева, но критично для линейных моделей.
4. Линейная регрессия уступает дереву на нелинейных данных.
5. Самый важный признак — **MedInc** (медианный доход), далее — **географические координаты**.

## 📈 Визуализации

- Дерево решений глубиной 3 (с правилами предсказания)
- Графики зависимости MAE от глубины дерева
- Feature importances
